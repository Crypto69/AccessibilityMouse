# AccessibilityMouse

Pointer speed and acceleration for each pointing device, made for people who use a
head mouse. Free for macOS 14+ and Windows 10/11.

**Website:** https://myaccessibility.ai/accessibilitymouse
**Download:** [latest release](https://github.com/Crypto69/AccessibilityMouse/releases/latest)

This repository holds the releases. The app's source code is private.

## Releases

Every release carries two files with these exact names, because the download buttons
on myaccessibility.ai link to `releases/latest/download/<name>`:

| File | Contents |
|---|---|
| `AccessibilityMouse-mac.zip` | The Mac app, signed with Developer ID and notarised. macOS 14 or later, Apple silicon and Intel |
| `AccessibilityMouse-windows.zip` | `AccessibilityMouse.exe` and `AccessibilityMouse.exe.config`. Windows 10 (1903 or later) or 11 |

Title each release with both versions, e.g. "Mac 1.1.3 · Windows 1.0.3"; the website
shows the title as the latest version.
